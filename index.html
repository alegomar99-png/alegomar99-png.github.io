Panel Redes

Aplicación privada de uso personal para consultar las estadísticas de mis propios canales de YouTube y organizar mi calendario de publicación.

Qué hace

  • Muestra en una sola pantalla seguidores, vistas, likes, comentarios y compartidos de mis canales.
  • Ordena los vídeos por rendimiento y muestra su curva de retención de audiencia.
  • Incluye un calendario con lo que toca publicar cada día.
  • De forma opcional, lee una hoja de cálculo propia para ver qué vídeos están pendientes.

Cómo funciona

Panel Redes se ejecuta solo en mi ordenador. No es un servicio abierto al público: esta página únicamente lo describe, y aquí no se muestran estadísticas ni datos de ninguna cuenta.

La aplicación accede con permisos de solo lectura mediante los servicios de API de YouTube, después de autorizarla con la cuenta de Google correspondiente. No puede publicar, editar ni borrar contenido.

Tus datos

La política de privacidad explica qué datos usa la aplicación, dónde se guardan y cómo retirar el permiso.

In English

Panel Redes is a private, personal-use application that runs only on its owner's computer. It uses YouTube API Services with read-only access to show statistics for the owner's own channels. See the privacy policy.
